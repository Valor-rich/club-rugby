# Club location metadata

Add location fields at the end of teams_meta.csv. Keep team_id unchanged. Use the physical senior home ground, not a postal address. Enter street_address, suburb, postcode, latitude, longitude, location_source (public URL), location_verified (YYYY-MM-DD). Coordinates are decimal degrees, negative latitude in Australia and New Zealand. Leave unverified values blank. A map appears only when both coordinates are valid; otherwise the profile provides a venue search and directions link. Verify coordinates against the home field itself before publishing. Canberra Royals address was checked against the Brumbies club directory and club website; coordinates are intentionally blank. Existing venue data for other clubs is unchanged and has not been verified.
